# Cosmic Civilizations

一个在本地浏览器运行的三维文明推演器。可旋转、缩放、选择文明，观察实际行动与延迟通信；支持真实模型、明确标识的离线规则模式、暂停、回放和存档。具体当次验收证据见 `output/` 与 `FINAL_REVIEW.md`。

## 本地运行

```bash
npm install
npm test
npm run build
npm run dev
```

开发服务约定为 Vite `127.0.0.1:4330`，API `127.0.0.1:4321`。端口或运行状态应以当前终端输出为准。启动后需要用真实浏览器操作创建、运行、暂停、恢复、导出和导入路径。

## 模型配置

服务端从 `.env` 读取模型配置，浏览器不接触 API key；`.env.example` 只提供空占位，不要把密钥写入 `VITE_*` 变量或提交到 Git。当前约定是 DeepSeek 的 OpenAI Chat 兼容协议：

```dotenv
LLM_PROVIDER=deepseek
LLM_PROTOCOL=openai-chat
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
```

参考 [DeepSeek 首次 API 调用文档](https://api-docs.deepseek.com/zh-cn/)、[Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。当前已通过真实 DeepSeek 2×2 请求验证；默认12×30的当次结果见 `output/real-default-validation.json`，不能把离线测试当成模型请求成功。

## 推演规则

规则真源是 `src/engine/index.ts` 导出的 `RULES`、`ACTION_SCHEMA` 和 `promptRules()`；本文只帮助阅读，规则改变时应同步检查代码和提示词。预算表示本次动作可用的上限，普通动作需满足 `decisionCost <= budget <= 当前资源`，`wait` 使用 `budget=0`；合作提案或接受还要把承诺资金计入冻结预算。

| 动作 | 目标 | 成本基线 | 作用 |
| --- | --- | --- | --- |
| `develop` | 无 | 8，强度变量 10 | 消耗资源，提升 technology/economy；是否增加 signature 以当前 `RULES` 和验收结果为准 |
| `explore` | 无 | 5，强度变量 5 | 提升 recon；下一次物理阶段发现资源地点和文明观测 |
| `hide` | 无 | 2 | 降低 signature，提升 stealth；与发展限制以当前引擎实现为准 |
| `defend` | 无 | 5 | 提升 defense，作用基于 tick 冻结状态 |
| `contact` | 本地 `contactId` | 3 | 至少延迟一个 tick 的 information 通信 |
| `broadcast` | 无 | 4 | 向当时存活文明发送延迟信息；signature 变化以 `RULES` 为准 |
| `cooperate` | 本地 `contactId` | 8，强度变量 8 | proposal/accept/reject 延迟状态机；proposal/accept 的本金承诺计入预算和 escrow，过期退款，有限收益必须守恒 |
| `strike` | 有定位的本地 `contactId` | 12，强度变量 20 | 根据发射时带误差的估计冻结命中，攻击至少延迟一个 tick |
| `salvage` | 本地 `siteId` | 3 | 延迟回收有限地点资源，重复回收不能制造资源 |
| `wait` | 无 | 0 | 不产生战略动作 |

动作 JSON 只有 `action/target/intensity/budget/message/reason/beliefUpdates`。目标只能是当前视图中的本地 handle；消息文本是数据，不能被当作系统指令。通信消息只能使用 `proposal/accept/reject/information`，且会经过长度、控制字符、目标、proposal 状态和已收到事件引用检查。

## Tick 与知识边界

每个 tick 先复制并冻结物理世界，批量结算到期 transit、资源生产、合作和环境事件，再进行探索发现与观测，之后才为存活文明生成 `VisibleView`。距离是用于延迟和侦测的抽象单位，不是现实天体物理模拟；资源来自初始化的有限地点和受上限约束的文明生产，合作收益必须来自已有 escrow 或有界研究收益。视图不包含真实 civilization ID、contactMap、siteMap、绝对真坐标或其他文明的全局真值；联系人和地点使用带误差的局部估计，并记录发生 tick、观测 tick、来源事件。

攻击发射、飞行和抵达是不同事件。命中不能使用抵达时的真实坐标倒推；同刻决策必须基于同一冻结输入。死者已经发射的攻击仍可抵达。预警需要满足侦察条件，并按延迟队列进入观察记录。环境、攻击、合作和拾荒事件应有事件 ID、参与者、事实、因果事件 ID和观察记录。

## 模式、故障与恢复

`mode` 为 `llm`、`offline` 或 `mixed`，每个请求记录 `source`（`llm`、`rules` 或 `template`）。默认故障策略是暂停；修复和网络重试共享一次预算，`requestLimit` 默认 500。缺少模型配置时必须报告配置错误，不能把模板或离线结果伪装成真实 LLM。

运行状态包含 pending tick、PRNG、generation、事件和请求记录。暂停后只补缺失决策；过期请求不能提交。快照必须验证版本、结构和 checksum，导入的 pending 状态可恢复；历史回放不应产生 LLM 请求。浏览器恢复使用 IndexedDB，优先恢复服务端最新状态；旧快照不能覆盖本机已完成轮次、已付费请求或叙事。快照使用 `cosmic-dag-v1` 无损去重 JSON，旧版展开 JSON 仍可导入；校验码覆盖编码内容，导入后重新校验世界和证据。文件大小上限为128MiB。

## 叙事边界

叙事只能从已提交事件生成四层事实卡（universe、civilization、relation、reflection）。模型只能排序和组织事实卡，不能自由新增事实、数字、因果或人物动机；每条展示内容必须保留真实事件 ID 和发生/观察时间。`template`、`rules`、`llm` 来源必须显式区分。

## 验证与限制

- `npm test`：当前 88 项测试全部通过，覆盖确定性、信息隔离、原子结算、双向合作、延迟通信、死者攻击、模型 mock 错误/超时/额度/修复、过期响应、叙事恢复、DAG 隔离、导入保护和第一人称控制。
- `npx tsx tests/stress.ts`：50文明×50轮，25轮导出导入后续跑，与连续运行逐字段校验世界和PRNG；运行后证据写入 `output/stress-50x50.json`。
- `output/llm-smoke-final.json`：真实DeepSeek 2×2人格、决策及四层叙事；包含开发期间失败修复记录。
- `output/playwright/`：真实浏览器桌面、移动抽屉与3D操作截图。截图不能单独证明全部路径通过。
- 模型输出仍可能非法；默认暂停并保留成功响应，用户重试或显式选择规则继续。不会自动加预算。
- 叙事采用模型组织已验证事实卡，表达空间受到约束；尚不是自由文学创作。
- 最大规模存档仍可能需要较多内存与数分钟，适合本地桌面；不承诺低内存手机上的50×50性能。
- 开发服务器热更新会触发恢复暂停。正式体验建议先 `npm run build`，再 `npm start`，打开API端口4321上的同一应用。

接手前先阅读 [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md) 和 [HANDOFF.md](HANDOFF.md)，再检查 `模型协作/` 中的当前阶段和验收门槛。

## 三维观察方式

拖动鼠标旋转宇宙，右键拖动平移，滚轮缩放；移动端使用单指旋转、双指缩放。使用“纵览宇宙”返回全景，“靠近选中文明”查看天体细节。行星表面、卫星、环和多星系统依据文明标识确定生成；这是文明的视觉表达，规则仍采用固定位置的一体文明，不包含迁移、殖民、真实天体物理或独立行星经济。

在途通信和攻击绑定队列 ID；颜色与文字共同区分类型。暂停时停止过程动画，相机仍可手动操作。文明详情区分“仅观众可见”的真值与文明实际收到的局部信息。

## 本轮体验修复（2026-10-16）

观察摘要按文明合并连续行为，按五轮汇总状态变化；联络、广播分别计数，原始依据默认折叠。文明使用稳定编号、短名、符号和颜色，模型原名仍保留。历史文明视图使用当时的白名单信息，不混入未来观察。

三维布局按主星、子星、卫星和星环的包围范围避碰；布局仅用于观众展示，不改变引擎位置和传播规则。攻击显示炮座、炮口、定向弹体与轨迹；通信有信号包和扩散波纹，探索、建设、防御、隐匿和回收有各自形态。只有实际伤害事件显示爆破，零伤害单独表示。暂停冻结过程，相机仍可手动移动；减少动态效果时显示静态状态。

真实运行 `877d1071-faaf-462c-a0ad-f319ec0431e8` 从故障第7轮恢复至30轮：385次请求、360条真实决策和四层真实叙事，0回退。修复后282次请求中3次首轮校验失败均一次修复成功，未再次故障暂停；原本成功的10个请求未重复。证据 `output/feedback-real-validation.json`。这不保证所有后续模型输出都合法，网络、配额和无法修复的错误仍会明确暂停。

动作视觉另用 `scripts/create-action-fixture.ts` 的离线固定决策验收，所有事件由真实引擎产生；这是测试用例，不能当作模型自行选择战争的证据。验收截图位于 `output/playwright/feedback-*` 与 `actions-*`。

### 2026-10-17：交流、模型与结局观察

- 在途交流使用连续的单向信号流：它表示一条已发出消息仍在传播，粒子不是额外消息；抵达后移除，暂停/历史回放/减少动态效果时冻结。播放倍率只改变展示与轮次调度。
- 文明外观包含海洋、冰封、熔岩、环形居住带、轨道站群、双星、多行星、旋臂星系、小行星蜂群、戴森阵列、棱晶构造体、中空星港十二类。默认12文明的主形态不重复；更大规模按稳定编号增加结构变体（星体/模块数量、间距与阵列构成），不只换色。轨道设施使用圆柱舱、接驳环与流线外壳，阵列太阳能板保留为薄片。它们是文明状态的程序化视觉表达，没有新增独立星球经济或殖民规则。
- 今后生成的人格使用不同动机、风险偏好与初始信任态度作为创作起点；人格是有偏好的先验，不能代表中立分布，也不能保证出现战争或灭亡。已成功生成的人格和历史决策保持原样。
- “全部存活”仅说明存亡统计，不代表从未冲突或永久安全。现有两次真实 12×30 记录均没有攻击，环境扰动也没有覆盖文明；因此不存在损伤。不要把这一结果当作引擎只支持全存活。
- `npx tsx scripts/audit-outcomes.ts` 可复跑 12 个固定离线 seed（无模型请求）：本次 30/50 轮均全存活，延长至 100 轮后 9 个样本出现 1–2 个文明灭亡，3 个仍全存活。结果见 `output/outcome-audit.json`。这不是对真实模型策略分布的验证，也不代表真实宇宙预测。
- 结局按时代、文明经历、往来与冲突、当前结局四层展示；每张事实卡单独成段，依据默认折叠，可跳转事件。时间以抽象轮次表示，不换算虚构宇宙年份。模型组织引擎事实卡，仍不生成未经证实的对白、动机或自由文学情节。
- 新叙事卡标记 `factVersion: 2`；旧卡与旧成功请求继续按 v1 验证。延长观察后保留每段历史叙事的截止时间。JSON/Markdown 可导出；导入校验未知版本和被改动的事实卡。
- 续看按钮显示基础请求估算与剩余额度；超过已有预算时仍按原故障策略暂停或显式回退，不自动加额。


## 2026-10-17 长轮数与第一人称控制

界面默认观察 100 轮，单段可设置 1 至 500 轮，阶段完成后可继续延长；请求预算默认 500，不会自动提额。第一人称接管一个文明后，用户只能从该文明冻结的局部视图选择合法行动，等待用户时不会伪造 wait，也不会把用户输入自动重复提交。观察者全景、第一人称视角和逐轮提交可以互相切换。

离线 12 文明 T100 档案验证保留 11 个文明、9349 个事件和 3 条在途记录，恢复后 world 与 PRNG 一致，0 次外部请求。真实第一人称小路径使用 4 次 DeepSeek 请求完成 2 次人格、1 次 AI 决策和 1 次结局，均首次成功，0 次回退；这不是 12×100 真实长跑证明。

重大动态浮层只显示真实引擎中的攻击预警、实际损伤、正研究收益和灭亡等重要变化。固定决策浏览器 QA 已验证预警查看、损伤、合作结果、灭亡、去重、重置和 390px 无横向溢出；证据在 `output/revision-browser-validation.json` 与 `output/playwright/`，固定决策 QA 不代表真实 LLM 策略。
