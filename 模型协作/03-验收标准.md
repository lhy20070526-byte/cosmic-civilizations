# 验收标准

## 引擎

- 同 seed 与同决策序列可重复；不同 seed 产生可观察差异。
- 物理 tick 与决策输入冻结；同刻攻击聚合，不受文明顺序影响。
- 0 资源不出现负数；成本、合作 escrow、有限地点资源守恒。
- 视图只含白名单字段和局部带误差知识；无真 ID、真名、绝对真坐标或全局真值。
- 通信、攻击、预警、合作、拾荒满足最小延迟；死者已发射攻击仍可抵达。
- 命中使用发射时估计定位并冻结；攻击事件含 launch/impact/destroyed 因果链。
- 合作 proposal/accept/reject/expiry 延迟可复验，过期 tick 不能接受，双方状态不能瞬间全局同步。
- 非法或缺失全体决策阻止提交；offline fallback 返回合法 JSON。

## 服务与恢复

- `npm test`、`npm run build` 在当前代码上通过，失败输出有记录。
- 真实 DeepSeek 2×2 至少覆盖创建、请求、tick、暂停、恢复、失败和补请求。
- 默认 12×30 有运行日志，包含 tick、source、request 计数、事件和终局/期限状态。
- pending tick、generation、PRNG 和请求记录可恢复；过期请求不能提交。
- 快照版本/结构/checksum 校验；历史重放不调用模型。

## 真实交互

- 用真实浏览器操作核心路径，确认可见内容、暂停/恢复、导入导出和错误提示。
- 构建、接口返回、截图和服务状态只能作为辅助证据，不能替代真实操作审看。
